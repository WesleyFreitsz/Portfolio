## ✨ Principais Features

O projeto foi construído com foco em uma experiência de usuário moderna e fluida, contando com:

- **Animações Dinâmicas:** Animações de entrada e de scroll utilizando **GSAP (GreenSock Animation Platform)** para uma navegação mais agradável.
- **Smooth Scrolling:** Navegação suave e performática implementada com **Locomotive Scroll**.
- **Tema Light/Dark:** Alternância de tema para melhor conforto visual do usuário.
- **Design Responsivo:** Interface totalmente adaptada para visualização em desktops, tablets e celulares.
- **Modais Interativos:** Visualização detalhada dos projetos em modais criados com **Framer Motion**.

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias e bibliotecas:

- **Next.js:** Framework React para produção.
- **React:** Biblioteca para construção de interfaces.
- **TypeScript:** Superset do JavaScript que adiciona tipagem estática.
- **Tailwind CSS:** Framework CSS utility-first para estilização rápida e responsiva.
- **GSAP:** Biblioteca profissional para animações de alta performance.
- **Framer Motion:** Biblioteca para animações complexas e gestos.
- **Locomotive Scroll:** Para a implementação do efeito de smooth scroll.
- **Lucide React:** Pacote de ícones.
